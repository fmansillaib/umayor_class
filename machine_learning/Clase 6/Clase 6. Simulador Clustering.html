Comparativa
s(i) = [ b(i) − a(i) ] / max{ a(i), b(i) }
a(i) = distancia media intra-cluster  ·  b(i) = distancia media al cluster vecino más próximo
SC = promedio de s(i) sobre todos los puntos
1

Para cada punto, mide su distancia promedio a los demás del mismo cluster → a(i).

2

Para cada cluster vecino, calcula la distancia promedio al punto; toma el mínimo → b(i).

3

s(i) = [b−a]/max{a,b}. Si s(i) > 0 el punto está bien asignado; si s(i) < 0, pertenecería mejor a otro cluster.

4

SC = media de todos los s(i). Valores > 0.5 indican estructura clara.

CH = [ SS_B / (K−1) ] / [ SS_W / (N−K) ]
SS_B = dispersión entre centroides (between)  ·  SS_W = dispersión interna (within)
1

Calcula el centroide global de todos los puntos.

2

SS_B: suma ponderada de dist² de cada centroide de cluster al centroide global.

3

SS_W: suma de dist² de cada punto a su centroide de cluster.

4

Normalización por grados de libertad. CH alto → clusters densos y bien separados.

DB = (1/K) · Σ_i max_{j≠i} [ (s_i + s_j) / d(c_i, c_j) ]
s_i = radio medio del cluster i  ·  d(c_i,c_j) = distancia entre centroides
1

Para cada cluster, calcula s_i: distancia media de sus puntos al centroide.

2

Para cada par (i,j), ratio = (s_i+s_j)/dist(c_i,c_j): cuánto se solapan.

3

Para el cluster i, conserva el peor vecino (ratio máximo).

4

DB = media de esos peores casos. DB cercano a 0 → clusters compactos y separados.
