## 📖 Descripción de Módulos

### 1. **Machine Learning**
**Objetivo:** Fundamentos y aplicaciones prácticas de Machine Learning

- **Contenido:**
  - Algoritmos supervisados (Regresión, Clasificación)
  - Algoritmos no supervisados (Clustering, Dimensionality Reduction)
  - Ensemble Methods (Random Forest, Gradient Boosting)
  - Validación y evaluación de modelos
  - Feature Engineering

- **Tecnologías:** scikit-learn, pandas, numpy, matplotlib

---

### 2. **Métodos de IA**
**Objetivo:** Técnicas avanzadas y métodos clásicos de Inteligencia Artificial

- **Contenido:**
  - Algoritmos de búsqueda (BFS, DFS, A*)
  - Optimización y Constraint Satisfaction
  - Sistemas de reglas y Conocimiento
  - Razonamiento lógico
  - Agentes autónomos y Multi-agent Systems

- **Aplicaciones:** Planificación, Diagnóstico, Toma de Decisiones

---

### 3. **Fundamentos de Deep Learning**
**Objetivo:** Aprendizaje profundo desde los fundamentos

- **Contenido:**
  - Redes Neuronales Artificiales (ANN)
  - Backpropagation y optimización
  - Convolutional Neural Networks (CNN) - para imágenes
  - Recurrent Neural Networks (RNN/LSTM) - para secuencias
  - Transformer Architecture - estado del arte
  - Transfer Learning y Fine-tuning

- **Tecnologías:** TensorFlow, PyTorch, Keras

---

### 4. **Procesamiento del Lenguaje Natural (NLP)**
**Objetivo:** Tecnologías para entender y procesar texto

- **Contenido:**
  - Preprocesamiento de texto
  - Word Embeddings (Word2Vec, GloVe, FastText)
  - Modelos secuenciales (LSTM, GRU)
  - Transformers y arquitectura BERT
  - Análisis de Sentimientos
  - Named Entity Recognition (NER)
  - Machine Translation
  - Resumen de textos

- **Tecnologías:** spaCy, NLTK, Hugging Face Transformers, PyTorch

---

### 5. **IA Generativa**
**Objetivo:** Modelos para generar contenido nuevo

- **Contenido:**
  - Variational Autoencoders (VAE)
  - Generative Adversarial Networks (GAN)
  - Diffusion Models (DDPM, Stable Diffusion)
  - Large Language Models (LLM)
  - Prompt Engineering
  - Fine-tuning de modelos
  - API de modelos generativos (OpenAI, Anthropic)
  - Aplicaciones: Generación de texto, imágenes, código

- **Tecnologías:** PyTorch, Hugging Face, OpenAI API, Stable Diffusion
