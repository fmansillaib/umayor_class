# Series de Tiempo

## Descripción

Estos datasets contienen observaciones ordenadas temporalmente, ideales para análisis de tendencias, estacionalidad y predicción.

## Características
- Datos ordenados por tiempo
- Pueden mostrar tendencias, estacionalidad y ciclos
- Útiles para aprender técnicas específicas de series de tiempo

## Cómo usar estos datos

1. Ideal para ejercicios de pronóstico
2. Perfectos para detectar patrones estacionales
3. Excelentes para aprender ARIMA, exponential smoothing, etc.

## Datasets disponibles

- **precios_acciones/** - Series de precios de acciones
- **ventas_mensuales/** - Series mensuales de ventas
