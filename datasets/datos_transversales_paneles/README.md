# Datos Transversales y Paneles

## Descripción

Estos datasets contienen observaciones independientes (transversales) o el mismo conjunto de entidades observadas en múltiples períodos de tiempo (paneles).

## Características
- **Titanic:** Clasificación binaria dicotómica (Sobrevivió/No sobrevivió)
- **Precios de Casas:** Regresión continua (predicción de precio)
- **Ventas de Empresas:** Target continuos, categóricos y dicotómicos

## Cómo usar estos datos

1. Ideal para ejercicios de clasificación y regresión
2. Perfectos para aprender técnicas de preprocesamiento
3. Excelentes para comparar modelos de diferentes tipos

## Datasets disponibles

- **titanic/** - Supervivencia en el Titanic
- **precios_casas/** - Predicción de precios inmobiliarios
- **ventas_empresas/** - Análisis de ventas empresariales
